# How to use

## For TAs

On the website, select your name from the dropdown and then click the button to clock in or out. It may take a few seconds to process your location and make sure it is close enough to allow you to clock in.

## For Staff

Running the command `npm install` will install the required packages.

Running the command `npm start` will start the server locally, refer to your deployment system of choice for public hosting.

Clicking the "View full logs" button on the website will take you to the logs page. The logs are sorted by time, most recent first. There is a dropdown that you can use to see only the logs for an individual TA, or return to viewing all logs.

Adding a name to the names.txt file will automatically add it to the database and the time clock the next time the server is restarted. Removing a name from the list will remove it from the time clock, but keep the entries in the database.
